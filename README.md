# Проект "Сервис рассылок "Django-Mailer"

## Описание:

Проект является курсовой работой к шестому и седьмому модулям обучающего курса Skypro "Профессия Python-разработчик".
Реализует сервис рассылок. Веб-приложение создано на Django. 

## Логика работы программы: 

Есть пользователи сервиса. Они могут создавать письма и получателей этих писем, а так же создавать рассылки.
Веб-приложение отображает статистику рассылок, фиксирует успешные и неуспешные попытки рассылок.

Так же в данном веб-приложении реализовано разделение прав пользователей. Есть обычные пользователи. 
Им доступен функционал работы с рассылками.
Есть менеджеры. Они могут просматривать список получателей рассылок, список самих рассылок, завершать их по своему 
усмотрению (например, если пользователь не оплатил сервис), просматривать список обычных пользователей, блокировать и 
разблокировать их.

В проекте используется серверное кеширование. Работа с БД методами django.

Проект проверен линтерами

## Установка:

1. Клонируйте репозиторий:
```
git clonegit@github.com:Vadimko4/mailing_list_service.git
```
или
```
git clone https://github.com/Vadimko4/mailing_list_service.git
```

2. Установите зависимости:
```
poetry install
```
3. Ознакомьтесь с инструкцией в файле database.ini.example и донастройте окружение (введите свои данные для БД и 
почтового сервера)

## Использование:

1. Установите и запустите программу серверного кеширования redis-server.exe
2. В shell вызовите команду python manage.py runserver
3. Перейдите в браузере по адресу http://127.0.0.1:8000
